## Что должно заработать

Приложение открывается в браузере телефона, ставится на экран «Домой» и
запускается без адресной строки. При первом запуске пользователь заполняет
анкету (пол, возраст, рост, вес, активность, цель) и получает дневную норму
ккал/Б/Ж/У, которую может поправить. Главный экран «Сегодня» похож на Yazio:
сверху кольцо «осталось ккал», под ним полосы Б/Ж/У, ниже 4 карточки приёмов
пищи с суммами, листание дней. Внизу панель вкладок с крупной центральной «+».
«+» открывает лист способов добавления, в таком порядке: «Сфоткать еду»,
«Сфоткать этикетку», «Штрих-код», «Недавние», «Ввести вручную». Первые три в
этом таске — заглушки, которые вызывают `openCapture(mode)` из модуля
`src/ui/capture.js`. Его создаст таск 03, а здесь создай файл-заглушку с
экспортом `openCapture(mode, ctx)`, который показывает «Скоро».
«Недавние» и «Ввести вручную» работают полностью. Через общий экран
количества/проверки запись сохраняется в выбранный приём пищи. Тот же экран
используют фото-режимы в таске 03, поэтому его надо выставить наружу (см.
«Что выставить»). Запись можно открыть, поправить и удалить. В настройках:
ключ Claude API (маска, сохранение; кнопку «Проверить ключ» оставь с
обработчиком, который вызывает `checkKey` из `src/ai.js`, его пишет таск 02 по
сигнатуре из interfaces.md), выбор модели, профиль/норма, экспорт/импорт JSON.

## Что выставить для таска 03

`openReview(ctx)` в `src/ui/review.js` — общий экран проверки перед сохранением:
- `{ kind: "items", items: [{name, grams, kcal, protein, fat, carbs}], source }` — список позиций (фото еды): правка названия, граммов (КБЖУ пересчитываются пропорционально), цифр, удаление позиции; каждая позиция сохраняется отдельной записью;
- `{ kind: "product", name, per100|null, perPortion|null, unit, suggestions, source, defaultGrams? }` — один продукт (этикетка, штрих-код, недавние): ввод граммов (или числа порций, если per100 null), кнопки-подсказки из suggestions, живой пересчёт; при сохранении продукт кладётся в «Недавние».
Выбор приёма пищи по времени (`mealByHour`) с переключением; кнопки «Сохранить» и «Отмена».
