## Что должно заработать

Из листа «+» три пункта ведут в настоящие сценарии:
1. **Фото еды**: «Снять» (камера) или «Из галереи», превью, необязательное
   поле уточнения, «Распознать» → индикатор → `openReview({kind:"items"})`.
2. **Фото этикетки**: снять → «Считываю этикетку…» → `normalizeLabel` →
   `openReview({kind:"product"})` с подсказками граммов (порция/упаковка).
3. **Штрих-код**: снять → `readBarcode` → `lookupBarcode` → найден → тот же
   экран продукта; не найден → «Продукта нет в базе» + кнопка «Сфоткать этикетку».
Ошибки: нет ключа → экран с инструкцией (console.anthropic.com → API Keys →
вставить в Настройки) и кнопкой «В настройки»; bad-key → «Ключ не подошёл»;
network/rate → «Не удалось связаться, попробуй ещё раз» + «Повторить» (фото не
теряется); `ok:false` → причина от ИИ + «Переснять». Двойное нажатие
«Распознать» не шлёт два запроса.

## Из брифа, дословно

> «Если я просто сфоткаю еду, если я сфоткаю заднюю этикетку, ну типа там, где калории написаны»
> «Если штрих-кода нет, то ну типа надо вручную вводить, а это бред, я считаю.»
