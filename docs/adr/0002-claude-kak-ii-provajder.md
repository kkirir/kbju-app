## Контекст

Распознавание еды, этикеток и штрих-кодов по фото держится на мультимодальной модели. Фото еды личные, и платит за ИИ сам пользователь.

## Решение

Все три режима распознавания работают через Anthropic Messages API. По умолчанию стоит модель `claude-sonnet-5-5`, в настройках можно выбрать более дешёвую `claude-haiku-5-5`. Строгий JSON получаем через tool use, на каждый режим своя схема.

## Почему

- **Gemini** отвергнут: на бесплатном тарифе присланные фото могут идти на обучение моделей.
- **OpenAI** пользователь не выбрал.
- Claude выбрал сам пользователь. Tool use даёт ответ по схеме, а не свободный текст, который пришлось бы разбирать.

## Последствия

- Без собственного ключа Claude приложение не распознаёт ничего: доступны только «Недавние», ручной ввод и поиск в Open Food Facts по уже прочитанному коду.
- Даже штрих-код читает модель, поэтому без сети и без ключа его не отсканировать.
- Промпты, схемы инструментов и разбор ответа заточены под API Anthropic. Чтобы сменить провайдера, модуль `ai` придётся переписать целиком, сохранив только его внешний контракт.
- Поведение API зависит от модели (см. 0005), так что каждую новую модель нужно проверять отдельно.
