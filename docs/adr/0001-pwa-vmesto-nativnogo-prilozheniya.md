## Контекст

Нужно приложение на iPhone, которое запускается с экрана «Домой». Платного аккаунта Apple Developer у пользователя нет.

## Решение

Приложение делается как PWA: статические HTML, CSS и JS на ES-модулях, без сборки и npm-зависимостей. Устанавливается через Safari («На экран Домой»), работает в standalone-режиме, оболочку кэширует service worker.

## Почему

- **Нативное приложение через Xcode** отвергнуто. Без платного аккаунта Apple сборка, поставленная на телефон, перестаёт запускаться через 7 дней, и её пришлось бы переподписывать каждую неделю.
- **Сборщик и npm-зависимости** не взяли: тогда пользователю пришлось бы что-то устанавливать, а статические файлы можно положить на любой хостинг как есть.

## Последствия

- Доступно только то, что умеет iOS Safari. Камера открывается через `<input type="file" capture>`, а не через живой видоискатель.
- Чтобы поставить приложение, его нужно выложить на хостинг с HTTPS. Это отдельный шаг, и он требует согласия пользователя.
- iOS может вычистить данные сайта, поэтому экспорт и импорт в JSON обязательны, а не просто удобство.
- Переход на нативное приложение означает переписать всё, кроме, может быть, модулей `nutrition` и `ai`.
