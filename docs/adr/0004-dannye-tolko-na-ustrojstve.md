## Контекст

Сервера нет (см. 0003), устройство одно, аккаунты и синхронизация в рамки не входят.

## Решение

Дневник, недавние продукты и настройки хранятся в IndexedDB на телефоне. Фото не сохраняются. На случай смены телефона есть экспорт всех данных в JSON (без ключа API) и импорт, который заменяет текущие данные.

## Почему

- **Облачная синхронизация с аккаунтами** отвергнута: ей нужен сервер, которого нет, а работать надо на одном телефоне.
- **localStorage** не подошёл: он синхронный, принимает только строки и мал по объёму для журнала, который растёт каждый день. В IndexedDB есть индексы по дате и имени продукта.

## Последствия

- Резервная копия существует только тогда, когда пользователь сам нажал «Экспорт». Если удалить приложение с экрана «Домой» или iOS вычистит данные сайта, дневник пропадёт.
- Импорт заменяет данные целиком, а не сливает их.
- Сменить схему БД можно только миграцией прямо на устройстве, и старые экспорты тоже придётся уметь читать.
- Добавить синхронизацию позже значит завести сервер, аккаунты и решать конфликты записей.
